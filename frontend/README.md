# IQ Mastery - Student Frontend

This is a premium, trendy student portal built with React, Tailwind CSS v4, and Framer Motion.

## Features
- **Modern Landing Page**: High-conversion design with smooth animations.
- **Student Dashboard**: 
  - Dynamic content based on student class.
  - Class 1-6: IQ Test Assessment.
  - Class 6 onwards: Career Aptitude Assessment.
- **Login System**: Secure access via Phone number and Date of Birth.
- **Responsive UI**: Optimized for all devices with premium dark mode aesthetics.

## Tech Stack
- React 19
- Tailwind CSS v4 (Alpha/Experimental features)
- Framer Motion
- Lucide React Icons
- React Router Dom v7

## Setup
1. `cd frontend`
2. `npm install`
3. `npm run dev`

## Structure
- `/src/pages`: Contains Landing, Login, and Dashboard components.
- `/src/App.jsx`: Main routing and user state management.
- `/src/index.css`: Tailwind 4 configuration and global themes.
